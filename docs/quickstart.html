Quickstart

От установки до первой поляры за 10 минут.

1. Установка SU2

AeroOpt — это только графическая оболочка. Само ядро расчёта (SU2) устанавливается отдельно.

Скачайте SU2 для вашей операционной системы с официального сайта su2code.github.io. Распакуйте архив, например, в C:\SU2 или /opt/SU2.

Проверьте, что SU2_CFD (или SU2_CFD.exe) доступен из командной строки: 

SU2_CFD --help

Должна появиться справка по опциям. Если команда не найдена, добавьте путь к SU2 в переменную среды PATH или запомните полный путь — он понадобится в шаге 4.

2. Установка Microsoft MPI (только Windows)

Для многоядерных расчётов на Windows требуется Microsoft MPI. Скачайте и установите msmpisetup.exe (версия 10.1.3 или новее).

После установки проверьте, что команда mpiexec доступна: 

mpiexec --version

На Linux OpenMPI обычно уже установлен. Если нет, поставьте пакет: sudo apt install openmpi-bin libopenmpi-dev.

3. Установка Gmsh

Gmsh нужен для генерации сетки. Скачайте с gmsh.info или установите через пакетный менеджер: 

sudo apt install gmsh      # Linux
brew install gmsh          # macOS
choco install gmsh         # Windows (Chocolatey)

Проверьте: gmsh --version. Версия 4.10 или новее.

4. Установка AeroOpt

Скачайте установщик из раздела загрузок на главной странице. Запустите его и следуйте инструкциям.

При первом запуске AeroOpt попросит указать путь к SU2_CFD.exe. Если вы добавили SU2 в PATH, оставьте поле пустым и нажмите «Авто-поиск». Если нет, укажите полный путь, например C:\SU2\bin\SU2_CFD.exe.

Введите ваш лицензионный ключ. Купить его можно на главной.

5. Создание геометрии

В левой панели выберите узел «Geometry 1 → Fuselage Generator». Задайте длину фюзеляжа (например, 8 м) и диаметр (1.2 м). Нажмите «Сгенерировать фюзеляж».

Затем выберите «Wing Generator». Задайте размах (10 м) и корневую хорду (1.8 м). Нажмите «Сгенерировать крыло».

В 3D-окне справа должна появиться модель самолёта.

6. Построение сетки

Выберите узел «Mesh 1» в дереве. В правой панели выберите качество сетки: «Грубая» для быстрой оценки, «Средняя» для нормального расчёта, «Точная» для финального.

Нажмите «Построить расчётную сетку». Это займёт от 30 секунд (грубая) до 5 минут (точная). В папке work/case_*/aoa_*/mesh.su2 появится файл сетки.

7. Запуск расчёта

Выберите узел «Solver Settings» в дереве. В разделе «Производительность и ресурсы» выберите число ядер CPU (например, 4) и режим вычислителя (только CPU). Включите «Плоскость симметрии», если ваш самолёт симметричный.

В разделе «Режим продувки» оставьте «Одиночный расчёт» и угол атаки 3 градуса. Нажмите «Запустить расчёт».

Следите за прогрессом в логе внизу. Когда расчёт закончится, в таблице результатов появятся CL, CD, CM.

8. Поляра

Для построения поляры переключитесь в режим «Поляра (Sweep)». Задайте начальный угол (например, 0°), конечный (12°) и шаг (2°). Запустите расчёт — он посчитает 7 точек подряд.

Перейдите на вкладку «2D Аэро Графики» внизу — там будет кривая CL(AoA).
