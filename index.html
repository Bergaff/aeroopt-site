AeroOpt

Десктопный графический интерфейс для SU2.

Возможности Цены Скачать Документация Кабинет

SU2 — это open-source решатель для аэродинамики. Он работает из командной строки и требует ручной подготовки сетки, файлов конфигурации и запуска mpiexec. AeroOpt оборачивает всё это в обычное оконное приложение для Windows и Linux.

Импортируйте STL или STEP. Задайте крыло, фюзеляж, оперение. Нажмите «Построить сетку», затем «Запустить расчёт». Получите CL, CD, поляру, визуализацию поля обтекания. На компьютере с видеокартой NVIDIA — ускорение в 5-10 раз.

Возможности

  1. Параметрическая геометрия. Крыло, фюзеляж, горизонтальное и вертикальное оперение, закрылки, предкрылки, излом крыла. Все размеры в метрах, профили NACA 4-значного кода.
  2. Построение сетки через Gmsh. Три уровня качества: грубая, средняя, точная. Автоматическая проверка, что в mesh.su2 есть маркеры airfoil и farfield.
  3. Запуск SU2 через mpiexec. Любое число процессов. Mesh partition для многоядерных машин.
  4. Гибридный CPU+GPU режим. На машинах с NVIDIA RTX 30xx/40xx и SU2, собранным с CUDA — ускорение в 5-10 раз. Автоматический фоллбэк на чистый CPU.
  5. Плоскость симметрии. Один клик — SU2 считает только половину модели. Ускорение примерно в 1.8 раза для симметричных самолётов.
  6. Euler и RANS. Невязкий Euler для быстрой оценки, RANS SA и RANS SST для вязких течений. RAMP-функции для устойчивой сходимости.
  7. Поляра (sweep). Несколько углов атаки в одной сессии. Результат — CL, CD, CM, K по каждой точке. Графики поляры.
  8. Оптимизация формы. Целевые CL и K. Параметрический поиск с учётом правил проектирования.
  9. Визуализация. Поле давления, число Маха, векторы скорости на поверхности. Цветовые шкалы. Сохранение в CSV и ParaView.
  10. Балансировка. По результатам расчёта: текущий Cm и потребный угол руля высоты для триммирования.

500 МБ для программы плюс место под проекты и расчёты. Типичный проект занимает 50-200 МБ.
Дополнительно
SU2 7.5 или новее. AeroOpt не включает SU2 — его нужно установить отдельно или указать путь к нему в Solver Settings.

Как это работает

AeroOpt не делает расчёт сам. Это графическая оболочка над SU2 — open-source решателем уравнений Навье-Стокса. AeroOpt готовит mesh.su2, пишет config.cfg, запускает mpiexec, читает history.csv и surface_flow.vtu, отображает результаты.

Если у вас уже есть опыт работы с SU2 из командной строки, AeroOpt покажется вам привычным. Если нет — документация ниже поможет начать.
