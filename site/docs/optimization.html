Что это такое

Оптимизация формы в AeroOpt — это параметрический поиск. Программа перебирает комбинации параметров крыла (размах, хорды, стреловидность, крутка, параметры закрылков) и для каждой комбинации считает аэродинамику через SU2. Лучший вариант, удовлетворяющий заданным целям, предлагается пользователю.

В текущей версии используется случайный поиск с 6 кандидатами. В версии 5.x планируется подключение adjoint-based оптимизации SU2, что позволит перебирать 50+ параметров за 20-30 итераций.

Параметры, которые оптимизируются

span (размах)
Полный размах крыла от законцовки до законцовки, метры.
chord_root (корневая хорда)
Хорда в корневом сечении крыла, метры.
chord_tip (концевая хорда)
Хорда в концевом сечении, метры. Не может превышать корневую.
sweep (стреловидность)
Стреловидность по передней кромке, градусы.
flap_deflection
Угол отклонения закрылков, градусы. Только если включены закрылки.

Целевые параметры

Задайте желаемые значения CL и K (аэродинамическое качество CL/CD). Программа ищет комбинацию параметров крыла, при которой эти значения достигаются.

Пример: для учебного самолёта задача «CL=0.45, K>=15» — найти крыло с подъёмной силой 0.45 и качеством не ниже 15.

Правила проектирования

В разделе Global Definitions → Design Rules задаются ограничения: минимальное удлинение крыла, максимальная толщина профиля, допустимый диапазон чисел Маха и так далее.

Оптимизатор проверяет каждое решение на соответствие правилам. Решения, нарушающие жёсткие правила, отклоняются. Решения, нарушающие мягкие правила, штрафуются.

Многоточечная оптимизация

Вместо одной точки AoA можно задать несколько (например, «крейсер» при 3° и «взлёт» при 8°). Оптимизатор найдёт крыло, которое хорошо работает на всех режимах, — то есть компромисс.

Это полезно, когда одно крыло не подходит одновременно для крейсерского полёта (где важен K) и для взлёта (где важен CL).

Запуск

В дереве выберите «Multipoint Optimization». Задайте целевые CL и K, при необходимости отредактируйте список расчётных точек. Нажмите «Запустить оптимизацию».

В логе появится информация о каждом кандидате. После завершения в строке статуса будет показан лучший результат.

Сколько это занимает времени

Каждый кандидат — это полный расчёт нескольких точек поляры. При сетке «Средняя» и 6 точках поляры один кандидат считается 5-15 минут на 6-ядерном CPU. Полная оптимизация (6 кандидатов) — от 30 минут до полутора часов.

На GPU ускорение в 5-10 раз, то есть оптимизация завершится за 5-15 минут.

Ограничения

  • Параметрическая оптимизация не меняет форму профиля — только размеры и положения. Для изменения формы профиля нужен adjoint-режим (5.x).
  • Случайный поиск не гарантирует глобальный оптимум. Для серьёзных задач используйте несколько запусков с разными seed-ами.
  • Аэродинамические правила (например, «отсутствие отрыва») не проверяются автоматически — только вручную по полю течения.
